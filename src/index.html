Hack the Agent

A live, multiplayer game that teaches prompt injection. [1]

Five levels, each better defended than the last

A host opens a session, the audience joins by QR code on their phones, and players try to trick five fictional agents:

  1. Level 1
    a system prompt only
  2. Level 2
    rules
  3. Level 3
    indirect injection through an inbox
  4. Level 4
    a refund desk with server-side checks
  5. Level 5
    a hardened agent with an instruction hierarchy, a tool allowlist, server-side authorisation and an output filter
What it shows
A trace of every tool call, a live request budget, rate limits, leaderboards and a presentation mode.
What he did
Designed and built the app.
In the newsroom's review
All three live attempts to break it were refused, and the output filter caught the last practice attempt. [1]

Step 2

How he works: fast, and checked

José moves quickly, and he builds the checks in from the start: tests, review, a watcher, and agents that stop short of sending. [1] [6]

  1. 1

    He builds fast

    At the Vibathon Algarve 2026 he built two working agent apps in a day: Hack the Agent and ReachCheck.

  2. 2

    Automations are tested code

    His automation agent keeps the n8n flows as tested code, so a flow can be read, reviewed and checked like any other program.

  3. 3

    A reviewer on every change

    A code-review agent reviews every diff before it is pushed.

  1. 4

    A security watcher

    A read-only security agent reports who committed what. It can see, but it cannot change anything.

  2. 5

    Agents draft

    His automation agent never sends. Agents draft, people send.

  3. A person sends

    The flow ends with a person: agents draft, and sending is left to a person.

Security in what he builds

Both of his Vibathon apps are about what an AI agent can reach and what stops it: prompt injection, tool allowlists, server-side authorisation, output filters, and checking an agent against what its owner authorised.

One job per agent

José works with a team of 14 agents (13 running), each with one job: an automation agent, a developer, a code reviewer, a security watcher, a setup helper, a sales coach, a conductor, a designer, a CRM agent, a vault agent, an accountant and a dashboard agent.
