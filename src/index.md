## Selected work

### Hack the Agent

A live, multiplayer game that teaches prompt injection, built in a day at the Vibathon Algarve 2026, at the University of the Algarve, in Lovable. A host opens a session, the audience joins by QR code on their phones, and players try to trick five fictional agents, each better defended than the last: a system prompt only; rules; indirect injection through an inbox; a refund desk with server-side checks; a hardened agent with an instruction hierarchy, tool allowlist, server-side authorisation and output filter. It shows traces of every tool call, a live request budget, rate limits, leaderboards and a presentation mode. In the newsroom's review, all three live attempts were refused, and the output filter caught the last practice attempt.

- Try it: https://agent-defense-arena.lovable.app/
- Source: https://newsroom.sgit.ai/articles/jose-botas-two-agent-apps.md (read 2026-11-16)

### ReachCheck

Built the same day, also in Lovable. Checks an agent's configuration against what its owner authorised, entirely in the browser.

- Try it: https://reach-check-agent.lovable.app/
- Source: https://newsroom.sgit.ai/articles/jose-botas-two-agent-apps.md (read 2026-11-16)
