Hack the Agent

A live, multiplayer game that teaches prompt injection. Built in a day at the Vibathon Algarve 2026, at the University of the Algarve, in Lovable.

What it is
A host opens a session, the audience joins by QR code on their phones, and players try to trick five fictional agents, each better defended than the last:
  1. a system prompt only;
  2. rules;
  3. indirect injection through an inbox;
  4. a refund desk with server-side checks;
  5. a hardened agent with an instruction hierarchy, a tool allowlist, server-side authorisation and an output filter.
It shows a trace of every tool call, a live request budget, rate limits, leaderboards and a presentation mode.
What he did
Designed and built the app. In the newsroom's review, all three live attempts to break it were refused, and the output filter caught the last practice attempt.

His agent team

José works with a team of 14 agents, 13 of them running. His agents made 277 commits on the team's site.

What it is
A set of agents, each with one job:
  • an automation agent that keeps the n8n flows as tested code and never sends;
  • a developer for automations and integrations (n8n, WhatsApp, the site);
  • a code reviewer that reviews every diff before it is pushed;
  • a read-only security watcher that reports who committed what;
  • a helper that gets anyone stuck on setup unstuck;
  • a sales coach that trains his RiskMandate pitch by role-play;
  • a conductor, a designer, a CRM agent, a vault agent, an accountant and a dashboard agent.
What he did
Runs this team of agents for his own work.
