Selected work

Two agent apps built in a day, the automation and messaging work behind a team at Web Summit, and the team of agents he works with. Each step links to the thing itself and to its public source.

  1. 01

    Hack the Agent

    Agent app

    A live, multiplayer game that teaches prompt injection. Built in a day at the Vibathon Algarve 2026, at the University of the Algarve, in Lovable. [1]

    What it is

    A host opens a session, the audience joins by QR code on their phones, and players try to trick five fictional agents, each better defended than the last:

    1. L1a system prompt only
    2. L2rules
    3. L3indirect injection through an inbox
    4. L4a refund desk with server-side checks
    5. L5a hardened agent with:
      • an instruction hierarchy
      • a tool allowlist
      • server-side authorisation
      • an output filter

    It shows a trace of every tool call, a live request budget, rate limits, leaderboards and a presentation mode.

    What he did
    Designed and built the app.
    Review

    In the newsroom's review, all three live attempts to break it were refused, and the output filter caught the last practice attempt. [1]

    • Live attempt 1: refused
    • Live attempt 2: refused
    • Live attempt 3: refused
    • Last practice attempt: caught by the output filter

03

How he works

Fast, and checked. José moves quickly, and he builds the checks in from the start: tests, review, a watcher, and agents that stop short of sending. [1] [6]

  1. He builds fast

    At the Vibathon Algarve 2026 he built two working agent apps in a day: Hack the Agent and ReachCheck.

  2. Automations are tested code

    His automation agent keeps the n8n flows as tested code, so a flow can be read, reviewed and checked like any other program.

  3. A reviewer on every change

    A code-review agent reviews every diff before it is pushed.

  4. A security watcher

    A read-only security agent reports who committed what. It can see, but it cannot change anything.

  5. Agents draft, people send

    His automation agent never sends: agents draft, and sending is left to a person.

  6. Security in what he builds

    Both of his Vibathon apps are about what an AI agent can reach and what stops it: prompt injection, tool allowlists, server-side authorisation, output filters, and checking an agent against what its owner authorised.

One job per agent

José works with a team of 14 agents (13 running), each with one job: an automation agent, a developer, a code reviewer, a security watcher, a setup helper, a sales coach, a conductor, a designer, a CRM agent, a vault agent, an accountant and a dashboard agent.
