01

Agent app

Hack the Agent

A live, multiplayer game that teaches prompt injection. Built in a day at the Vibathon Algarve 2026, at the University of the Algarve, in Lovable.

A host opens a session, the audience joins by QR code on their phones, and players try to trick five fictional agents, each better defended than the last.

The five levels

  1. A system prompt only
  2. Rules
  3. Indirect injection through an inbox
  4. A refund desk with server-side checks
  5. A hardened agent with an instruction hierarchy, a tool allowlist, server-side authorisation and an output filter
What it shows
A trace of every tool call, a live request budget, rate limits, leaderboards and a presentation mode.
What he did
Designed and built the app.

How he works: the house rules

Fast, and checked

José moves quickly, and he builds the checks in from the start: tests, review, a watcher, and agents that stop short of sending.

  1. Agents draft, people send

    His automation agent never sends: agents draft, and sending is left to a person.

  2. He builds fast

    At the Vibathon Algarve 2026 he built two working agent apps in a day: Hack the Agent and ReachCheck.

  3. Automations are tested code

    His automation agent keeps the n8n flows as tested code, so a flow can be read, reviewed and checked like any other program.

  4. A reviewer on every change

    A code-review agent reviews every diff before it is pushed.

  5. A security watcher

    A read-only security agent reports who committed what. It can see, but it cannot change anything.

  6. Security in what he builds

    Both of his Vibathon apps are about what an AI agent can reach and what stops it: prompt injection, tool allowlists, server-side authorisation, output filters, and checking an agent against what its owner authorised.
